## Choices made (easy to change)
- Variables stay in a frame dictionary (as the interpreter), not Python locals: the unset-variable-is-its-own-name
  rule, globals and script locals come out right without analysis. Cost: no speed gain.
- `switch` runs one case and stops (as the interpreter does, which matches every golden case). LiveCode
  falls through to the next case when there is no break; neither path does that yet. Worth a golden case.
- A trailing `break` in a case is dropped; any other break raises Break, caught around that switch.
